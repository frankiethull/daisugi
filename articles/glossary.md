### Core Verbs

daisugi standardizes machine workflows through a small set of
forestry-inspired verbs.

“`grow_*()`”: fit or train a machine  
“`harvest_*()`”: generate predictions  
“`trees"`: unified argument for rounds / iterations / estimators

------------------------------------------------------------------------
