# Grow Fair Trees

Grow Fair Trees

## Usage

``` r
grow_fair_trees(x, y, s, trees = 100L, task = "classification", ...)
```

## Arguments

- x:

  a data X

- y:

  a data Y

- s:

  a contraint group sensitivity for fairness

- trees:

  num of trees

- task:

  a task

- ...:

  other eng args

## Value

a fitted fairgbm model
