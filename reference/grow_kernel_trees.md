# Grow kernel-Based Generative Trees

Grow kernel-Based Generative Trees

## Usage

``` r
grow_kernel_trees(x, y, trees = 100L, task = "classification", ...)
```

## Arguments

- x:

  a data X

- y:

  a data Y

- trees:

  num of trees

- task:

  a task

- ...:

  other eng args

## Value

a fitted model
