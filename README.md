## daisugi: not-so-well-known tree machines

<!-- badges: start -->

<!-- badges: end -->

The goal of daisugi is to curate novel tree & boosting algorithms for
use in R. daisugi unifies machines that are 1) not on CRAN, 2) not
directly available in R, 3) or well known. Hence, daisugi does not have
XGBoost, lightGBM, or catboost support. Those can be found via their
base repos or supported via bonsai in tidymodels.
